# Snippets

Código de nodos Code que conviene leer por separado.

- [`armar-saldos.js`](armar-saldos.js): nodo *Armar saldos* del bot de Telegram. Arma la respuesta de "¿cuánto tengo?" con la pestaña `Saldos` (ARS, USD, EUR) y la pestaña `Cripto` (Binance), y suma la cripto solo a los dólares. Es la versión más nueva de ese nodo; el JSON del bot en `workflows/` puede tener una anterior.
